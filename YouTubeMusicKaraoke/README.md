# YouTube Music Karaoke — Phase 1 starter

SwiftUI iOS starter for a lyric display prototype.

## Included
- SwiftUI lyric screen and simulated playback clock
- LRC timestamp parser
- LRCLIB synced-lyrics search service

## Not included / not verified
- YouTube Music audio playback or account integration
- Automatic track recognition or synchronization with YouTube playback
- Word-by-word karaoke timing
- CarPlay UI or entitlement approval
- App Store / TestFlight signing

YouTube Music playback is not exposed here as a supported public playback API. CarPlay lyric display is subject to Apple's supported CarPlay categories and entitlements; personal use does not bypass those restrictions.

## Build
Open `YouTubeMusicKaraoke.xcodeproj` in Xcode 15 or later. Select an iOS Simulator and build the `YouTubeMusicKaraoke` scheme.
